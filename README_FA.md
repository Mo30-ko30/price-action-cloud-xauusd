# Price Action Signal Pro — Cloud test for XAUUSD

این پروژه نسخه آزمایشی آنلاین منطق اکسپرت MQ4 شماست. فقط سیگنال می‌سازد و هیچ سفارش معاملاتی اجرا نمی‌کند.

## محدودیت‌های مهم
- داده‌ها از API عمومی biquote دریافت می‌شوند، نه مستقیماً از سرور آلپاری؛ بنابراین قیمت، منطقه زمانی/زمان کندل و سیگنال ممکن است با Alpari MT4 متفاوت باشد.
- GitHub Actions یک سرویس اجرای زمان‌بندی‌شده است، نه سرور دائمی. اجرای برنامه ممکن است با تأخیر انجام شود؛ این نسخه برای آزمایش است، نه هشدار تضمین‌شده یا معامله حساس به زمان.
- اندیکاتورهای Python ممکن است به دلیل تفاوت روش محاسبه EMA/RSI/ATR و ایچیموکو دقیقاً برابر MT4 نباشند.
- ابتدا روی حساب دمو و با مقایسه نمودارها آزمایش کنید.

## 1) ساخت ربات تلگرام
1. در تلگرام `@BotFather` را باز کنید و `/newbot` بفرستید.
2. توکن ربات را دریافت کنید؛ آن را در چت یا کد عمومی منتشر نکنید.
3. ربات خودتان را باز کنید و `/start` بفرستید.
4. برای به‌دست‌آوردن chat ID می‌توانید پس از پیام دادن به ربات، در مرورگر این آدرس را باز کنید:
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
   مقدار `message.chat.id` را پیدا کنید. توکن را در URL عمومی یا اسکرین‌شات منتشر نکنید.

## 2) ساخت مخزن GitHub
1. وارد https://github.com شوید و یک repository جدید بسازید.
2. برای تست ساده‌تر می‌توانید Public را انتخاب کنید؛ در مخزن عمومی هیچ توکن یا اطلاعات شخصی قرار ندهید. اگر Private انتخاب کردید، سهمیه رایگان Actions حساب را بررسی کنید.
3. فایل‌های همین بسته را در مخزن آپلود کنید، از جمله پوشه `.github/workflows`.
4. در Settings → Secrets and variables → Actions → New repository secret دو secret بسازید:
   - `TELEGRAM_BOT_TOKEN` = توکن BotFather
   - `TELEGRAM_CHAT_ID` = شناسه چت خودتان
5. در Actions، workflow با نام `XAUUSD Price Action Signal` را انتخاب و `Run workflow` بزنید.
6. در اجرای موفق، بخش Logs را ببینید. اگر روی آخرین کندل بسته‌شده سیگنال وجود داشته باشد، پیام تلگرام می‌آید؛ در غیر این صورت فقط WAIT در لاگ ثبت می‌شود.

## 3) زمان‌بندی
Workflow به‌طور اسمی در دقیقه‌های 03، 18، 33 و 48 هر ساعت UTC اجرا می‌شود. GitHub ممکن است اجرای زمان‌بندی‌شده را به تأخیر بیندازد یا در زمان‌های شلوغ صف‌بندی کند. این فاصله 15 دقیقه‌ای برای تست کندل M15 انتخاب شده است.

## 4) تنظیمات استراتژی
پارامترهای اصلی از MQ4 شما منتقل شده‌اند: EMA H1 50/200، EMA M15 20/50، RSI/ATR 14، ایچیموکو 9/26/52، حمایت/مقاومت 20 کندل، امتیاز حداقل 5، حد ضرر ATR × 1.5 با حداقل ریسک ATR × 0.8 و اهداف 1R/2R.

## 5) حریم خصوصی و امنیت
- توکن تلگرام را فقط در GitHub Secrets نگه دارید.
- اگر توکن افشا شد، از BotFather آن را باطل و دوباره تولید کنید.
- فایل state.json فقط زمان آخرین کندل بررسی‌شده را نگه می‌دارد.
- هیچ تابعی برای ارسال سفارش به بروکر در پروژه وجود ندارد.
